# Rhythm Game School Project

학교 배경의 3D 리듬 게임 프로젝트입니다. 유니티(Unity) 엔진을 기반으로 하며 MMD 캐릭터 모델(미나, 민우)을 활용합니다.

## 🎮 주요 기능 (Features)

### 1. 로비 (Lobby)
- **학교 교실 배경**: 3D 교실 환경에서 캐릭터들이 대기합니다.
- **메인 메뉴 UI**: 스포티/쿨 테마의 감각적인 UI 디자인.
- **캐릭터 상호작용**: 캐릭터 클릭 시 반응하거나 커스터마이징 메뉴로 이동합니다.
- **아이템 샵**: 인게임 재화(Coin)를 사용하여 곡, 스킨 등을 구매할 수 있습니다.

### 2. 곡 선택 (Song Selection) - **[NEW!]**
- **커버 플로우 (Cover Flow)**: 앨범 아트를 가로로 넘기며 곡을 선택하는 직관적인 UI.
- **Selection**: `GALAXIAS!`, `SODAPOP` 등 다양한 곡 선택 가능.
- **Lock System**: 해금되지 않은 곡은 잠금 표시되며 플레이할 수 없습니다.

### 3. 리듬 게임 (Ingame)
- 노트 판정 및 콤보 시스템.
- 모바일 컨트롤러 연동 지원 (QR 코드 접속).

## 🛠 최근 변경 사항 (Updates)
- **UI 리파인**: 로비 버튼 디자인을 '다크 인디고' & '형광 사이언' 테마로 전면 개편.
- **곡 선택 UI 개선**: 기존 리스트 방식에서 **커버 플로우(Carousel)** 방식으로 변경.
    - 앨범 아트 잘림 현상 해결 및 레이아웃 최적화.
    - 직관적인 'GAME START' 버튼 배치.

## 🕹 조작 방법 (Controls)
- **UI 탐색**: 마우스 클릭
- **스크롤**: 드래그 또는 마우스 휠
- **게임 플레이**: 키보드 (설정된 키)

## 🚀 실행 방법 (How to Run)
1. Unity 2020.3.x 버전 이상에서 프로젝트 열기.
2. `Assets/Scenes/Lobby` 씬 실행.
